# Benchmark UI screenshot provenance

Captured for this project by Codex on 2026-10-23 with official Godot 4.7.2, using
`tools/test_benchmark.py --screenshots --players 2 4 --gpu-index <INDEX>` and
`game/tests/test_benchmark.gd`. These are direct 1600x900 viewport PNG exports
from isolated synthetic test data. The selected captures show this project's
performance-test interface, text and frame-time graph, without a 3D sports world.
No external image, photo, reference artwork, image generation or pixel editing
was used. The UI is original Regina Sports MIT code; these UI screenshot outputs
are distributed under the same MIT license. No font binaries or new third-party
art files are included.

These are short functional acceptance runs (0.1 s warmup / 0.3 s sampling, low
quality), not the default-duration benchmark or a performance baseline. The
complete acceptance ZIP retains the original captures, reports and per-file
hashes. Existing project asset notices remain in `docs/THIRD_PARTY.md` and
`docs/ASSET_PROVENANCE.md`; this record does not relicense those assets.
