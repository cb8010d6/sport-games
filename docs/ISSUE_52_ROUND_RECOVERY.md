## 已实现行为（运行验证待做）

1. 射箭每支待射箭有 20 秒有效比赛时间，按键反复按下、断线或重连不重置时限。到期未出手按 0 环消耗这一箭，取消未释放的拉弓状态；已经飞出的箭按原物理结算，不能超时后再重复扣箭或加分。
2. 保龄球每次准备投球的 AIM 最多 20 秒；到期消耗一次 0 瓶投球，复用正常计分和换球／换格规则。原 SWING 最长 6 秒自动出手与 ROLLING／SETTLE 的有限时长保留，进入 SWING 不得重新获得另一段 AIM 时间。首球超时不清空仍站立的球瓶，第十格加球仍按正式规则处理。
3. 大赛允许在场的原参赛者全部准备后继续，不要求缺席者回到大厅；至少一名在场玩家才能开局。缺席者本项目加 0 大赛积分，保留此前积分及原始参赛槽位，后续项目可以重新加入；在场玩家按其本项目实际竞赛名次获积分。大厅与成绩明确说明缺席计分规则，不把缺席者当成并列最后一名发保底分。下一项缺席与比赛中保留槽位是不同情况，不能靠移除 PLAY 玩家规避两个项目的时限。
4. 大赛会话仍有效时（包括总领奖台），大厅／成绩页首次 C 只显示退出确认；只有同一有效在场手柄在 3 秒内再次 C 才返回菜单并清空大赛，恰到3秒须重新确认。其他按钮、切换阶段、重开或该手柄断线取消确认；不能由两个不同手柄的一次误触凑成确认。确认者必须是当前玩家对象持有的已连接手柄及原参赛槽，陌生对象不能借同编号确认。普通单项目仍沿用一次 C 返回；总领奖台A返回及暂停菜单明确选择“回菜单”的现有路径保留，相关C提示同步为二次确认。
5. 所有玩法时限使用现有 `delta`／阶段时钟，树暂停即冻结；重开、换箭、换球及换项目必须重置对应状态。演示机器人和 benchmark 不获得额外分数，也不写玩家纪录。
