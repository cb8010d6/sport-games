# 高尔夫 G3-B：果岭共边细化

本片接在[G3-A](GOLF_G3_A.md)之后，属于未完成的M1。实现与验证正在进行；尚未声明性能门槛通过。只改surface、course的细化patch准备及专用测试，不改shader、素材、公共框架、洞位、OB或球物理。沿用含电脑全员完成/封顶后换洞，以及占位局禁纪录。

## 几何与查询

`RSGolfSurface.build(origin,cells,sample_height,patches)`接受粗单元半开矩形，重叠patch取并集。course使用各果岭最大半径加`5+sqrt(2)`米，向外对齐2.5m粗单元，覆盖1m插值场的果岭/边缘。

- 规范顶点以相对原点的0.25m整数key标识；粗角相隔10单位、细格步长2单位、fan中心为(5,5)。构建字典只存活于build，唯一顶点只采样一次；运行查询不回调公式、不分配数组或字典。
- 细化粗单元发出5×5个0.5m小格、50片三角。普通粗格保留原对角线的2片三角；有k条边邻接细格的粗格，在对应边插入4个点并以中心fan发出`4+4k`片三角。
- 所有chunk复制同一规范顶点/索引/法线缓存；跨第48单元仍共享过渡边，不留下T形裂缝。
- `normal_at`插值并归一化全局面积加权顶点法线，与渲染使用同一原始数据；`geometric_normal_at`返回所选三角的向上面法线。两者有意替换A的两种旧差分法线。
- `triangle_at(x,z)`返回真实三角id，域外返回-1；`cell_triangles(cell)`给出(first,count)，每格最多50片；`triangle_vertex(id,corner)`只读实际缓存。共享边按固定单元/三角顺序选面。
- 最大边缘进入最后单元的精确闭边界，移除A的`1.001`偏移；height/normal查询保留有限域外坐标夹取。域内找不到三角会报错，无双线性或raw公式回退。
- 未构建、非有限查询、无效矩形/索引/采样都明确报错；查询失败返回NaN/-1/null，失败build清掉旧有效缓存。局部坐标和高度限±4096m以约束float32误差，粗格上限250000、三角上限300000，均高于两图需求。矩形检查先减法约束尺寸，避免end溢出。

## 当前证据

Godot4.7.2受控导入通过。首轮发现mesh法线回读不满足原附加1e-5断言；解析单三角实证可由`octahedron_encode → floor(component*65535)/65535 → octahedron_decode`精确复现，平面向量距离6.20e-5、原cache/query误差0。显式codec必须保持Vector2乘法的float32分量舍入；脚本标量double乘法会在少量截断阈值产生相邻编码。仅分离渲染编码预算，未修改运行时以迁就测试；1mm高度及独立area要求不变，失败原始日志均保留。

- surface正常2508项及11个隔离拒绝用例通过；468442个实际三角查询、105次真实引擎射线。高度最大误差0.000001580m，面法线误差0；所有地图chunk顶点解码值与显式codec逐值相等。
- 顶点原normal到mesh解码最大距离0.000111748，插值mesh/query最大距离0.000105140；原cache的独立全局面积法线仍满足1e-5。
- 必需工具71项+130子测试、Hub62项、Node8项、规范0错误（3个既有SIZE警告）、翻译477/0/0、Ruff和发布扫描1190文件/0发现通过。
- 两图1/2/4人完整886项规则/生命周期矩阵通过，无额外错误、环境诊断或纪录文件；公共smoke待串行窗口。headless结果不证明画面或性能达标。

粗网格现有GPU诊断低FPS且波动明显；不能由此宣称B成本已在5%内。维护者负责独立、串行、同配置实渲染比较；4人平均FPS下降超过5%或载入增加超过1秒即暂停。未通过前不继续下一片，不降低确认的0.5m精度来回避门槛。
