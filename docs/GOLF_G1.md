# 高尔夫 G1：最小可玩回合

依据维护者批准的 [G0](GOLF_DESIGN.md)，本片只接通独立球场场景与公共回合框架。

- `golf_game.gd/.tscn`：两张现有地图、每图三洞、1–4人同时独立球/视口；每洞150秒有效时间、`par+4`封顶，已完成洞累加Stableford到`p.score`，沿用公共并列名次和成绩页。
- `golf_state.gd`：每人放在`p.data`；同一状态入口供真人占位按键和demo使用，不在core或其它项目放高尔夫逻辑。
- **临时输入**：A循环60/120/220米；按住B再松开沿现有`aim_point()`打向推荐目标；C取消。球沿1.2秒程序抛物线飞到目标；能到旗杆时自动进洞。半径0.12米为可见性占位。
- 这不是G2完整规则、G3真实球物理或G4手势；没有水/OB/树/弹跳/滚动/挥杆阈值，也没有机器人难度校准。现有球场与资源均保留，已知OB缺口仍待G3。
- **所有G1局禁写纪录**：覆盖已有`can_record()`返回false，包括真人；正式启用须等规则、球、手势与集成验收齐全。无新存档。
- 倒数、暂停、重开、分屏、成绩沿用RSPartyGame；暂停取消待出手并冻结球/计时，重开清局；地图重建释放旧球场/天空/太阳；玩家移除与场景释放清理球及公共信号连接。
- 洞间目前停留6秒，未绘制记分卡；开场/镜头演出在G5/G8，HUD/记分卡在G6等PR #27合入，未自建主题。
- 未注册目录或菜单，不改core、菜单、CI、公共smoke列表或原`golf_course.gd`；`--game=golf`须等维护者后续目录接入。

直接进入开发场景（`<Godot>`为项目认可的Godot 4.7.2）：

```sh
<Godot> --headless --fixed-fps 60 --path game res://scenes/golf/golf_game.tscn -- --map=0 --demo=4
python tools/test_golf.py --godot <Godot>
```

专用测试使用临时APPDATA/XDG目录和`RS_TEST_MODE=1`，两地图×demo1/2/4各独立进程；不需要catalog条目。验证自然跑完三洞、Stableford输出、重复结束、占位输入取消/重复松开、150秒封顶、暂停/重开/地图/玩家/场景释放及不产生`records.cfg`。

2026-10-24实际验证：Godot 4.7.2两次managed import通过；上述专用runner六组均通过，每图1/2/4人分别47/51/59项，共314项、0失败、0环境诊断，没有`records.cfg`或退出资源泄漏。逐组日志在本地忽略目录`audit-output/golf-g1/`；首次测试发现的WeakRef严格类型错误及测试音频收尾问题已修复后重跑全矩阵。
统一检查：工具69项及130个子测试、hub 62项、Node 8项均通过；规范0错误（3个原有SIZE警告），翻译475条/0缺失/0多余，Ruff与差异空白检查通过。素材校验222项、0下载、0缺失。公共smoke runner通过；既有项目仍报告退出资源保留警告，该runner明确不将其作为启动失败，不能据此声称全项目无资源泄漏。
