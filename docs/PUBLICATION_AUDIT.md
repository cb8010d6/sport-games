# GitHub 发布前审查

日期：2026-10-21。范围仅为 sport-games 仓库，不包含父目录其他开发者的项目。

当前结论：已实施本机信息清理，素材分发改为普通 Git + 原站下载，不使用 Git LFS。
先前待确认的 39 个成品已按项目提供者明确确认的 AI 原创记录；这一依据与可独立查阅的第三方
来源分开列出。审查通过表示没有未解释的扫描命中或未分类素材，不构成独立的法律保证。

## 发布范围和分发

- 生成成品和源码通过普通 Git 分发；资源清理后的具体数量与大小见 [ASSETS.md](ASSETS.md)，
  最大单文件约 22.3 MiB。当前待发布素材没有超过 50 MiB 或 100 MiB 的文件。
- 58 组、222 个 Poly Haven 原站二进制文件被 Git 忽略，约 763 MiB，改由下载脚本恢复。
  来源、格式、尺寸与原始/最终 SHA-256 记录在 tools/assets.lock.json。
- glTF 描述、Godot .import / .uid 和素材署名仍在仓库内。忽略规则保留本机已有文件。
- 取消根目录 LFS 属性并移除本次初始化的仓库本地 LFS 钩子；未改动全局 Git 设置。
- 本机证书、密钥、虚拟环境、构建目录、日志、录制、工具下载、私人 Blender 配置和可选桌面 ICO
  被排除。其他开发者在父目录的源码、驱动和素材未复制进本仓库。

完整操作见 [ASSETS.md](ASSETS.md)。

## 隐私处理

- Godot 启动器用环境变量、PATH 或相对位置定位；固件构建通过 IDF_PATH / IDF_TOOLS_PATH
  和独立驱动路径配置。文档中的个人安装路径、硬件描述和本机清理待办已整理。
- 文档 IP 示例改为占位符；代码中的通用路由探测目标不是保存的本机地址。
- 一张沙地纹理的 EXIF Software、EXIF ImageHistory、IPTC OriginatingProgram 含电脑路径，
  已清理。图像编码数据清理前后逐字节一致；下载脚本执行同一清理并验证最终 SHA-256，
  防止重新下载时恢复路径。其他元数据、来源署名与许可保留。
- 纹理图像编码数据的 SHA-256 为 38fdcea01fc7b7d3e97b4340fcf11498b7b1dc4d1e5611f35ab5219567420069。
