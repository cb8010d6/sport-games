# 阶段一：交互与画面回归

2026-10-22，基于已合并的 PR #2。此阶段补自动验证，修复验证中发现的 HUD 重叠；不新增玩法或控制器协议。

## 自动化覆盖

`python tools/test_lifecycle.py` 运行六项目 × 2 / 4 人，共 12 组真实场景交互。测试通过本机 UDP 的现有 roster / input 消息接入合成手柄，检查：

- 加入、准备、倒数、进入比赛；大厅断线会移除玩家，重连后必须重新准备。
- 比赛中断线 / 重连保留同一个玩家对象和分数。
- D 打开暂停，游戏时钟冻结；A 通过暂停菜单恢复。
- 通过暂停菜单重开，旧分数清零；重复结束调用仍保持已结算状态。
- 等待项目实际的回放 / 领奖台延迟后，A 返回大厅；C 返回实际主菜单。
- 每个分屏都有有效相机、正尺寸，彼此不重叠且没有越出窗口；四人教学卡片存在。

默认输出 `audit-output/lifecycle/`，包含逐例日志、JSON 及 HTML 画廊。非零退出、脚本 / 引擎错误、缺少完成标记、错误报告或不足数量的断言均不能通过。

图形布局检查：

```sh
python tools/test_lifecycle.py --screenshots --all-maps --languages zh en
```

该模式检查比赛开始后的布局并保存截图，不替代完整回合测试。临时用户目录与本次运行的 GPU 缓存共用，和玩家真实存档隔离；结束时只清理该运行目录，并重试 Windows 缓存写入竞态。

## 结果与修复

- 六项目 12 组交互通过。
- 全部 10 组地图 × 2 / 4 人 × 中英文，共 40 组图形检查通过，原始截图均为 1600×900；另保存各地图四人教学截图。
- 已查看全部地图的截图拼图及六项目中英文教学卡片。发现射箭英文拉弓提示与右下角本轮分数重叠，已上移提示；保龄球英文提示按可用宽度缩放，避免窄分屏超宽。
- 两个 HUD 修复后，重新跑中英文 × 2 / 4 人共 8 组截图检查并查看；射箭 / 保龄球的 2 / 4 人完整机器人回合另外回归。
- 本地引擎为 `4.7.2.stable.regina_ridfix1`，图形检查实际使用 Vulkan Forward+ / RTX 4060 Laptop GPU，低画质。此次检查不报告帧率目标或性能结论。
- 工具 51 项测试及 43 个子测试、中枢 62 项、素材工具 8 项通过；中英文 366 文本，零缺失 / 冗余；规范零错误（四个已有 SIZE 警告）。

本地证据位于 `audit-output/phase1-controls/`、`phase1-layouts/`、`phase1-layout-fixes/`。源码 CI 跑飞机 / 射箭 / 保龄球；带完整素材的 Windows package 工作流覆盖全部六项目，并上传交互报告。
