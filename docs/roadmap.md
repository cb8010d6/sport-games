# Regina Sports 总体计划

更新：2026-10-22。做完一项就把 `[ ]` 改成 `[x]`。规模：S = 一两次对话，M = 几次，L = 一个大块。

## 目标

做一款完整的**体感运动派对游戏**：拿起 Regina 手柄或手机就能玩，1–4 人同屏，有十几个运动项目。目标是像一个完整的游戏，而不是小游戏合集。

- **硬件**：Windows 电脑 + Regina 手柄 / 手机网页手柄
- **画面**：真实 CC0 素材、MPFB 人物、开场 / 回放 / 领奖台
- **体验**：
  - 第一次拿到就会玩，有新手教学
  - 一个人也能玩，有电脑对手和挑战
  - 几个人能连续比一整晚，有派对模式和总积分
- **完成的标准**：
  - 打包成一个安装包，不需要装 Python 和 Godot
  - 在公开定义的参考硬件上用推荐设置流畅运行

## 现状

**内容**：
- 6 个项目：螺旋桨飞机、射箭、保龄球、滑板、滑雪（4 张地图）、篮球（2 张地图）
- 高尔夫做了一半，只有球场

**通用功能**：
- 大厅、分屏、倒数、成绩、暂停菜单
- 震动
- 画面设置：VRR / HDR / FSR / 画质 / 窗口模式
- 中英文
- 一键启动
- 主菜单设置、玩家 / 手柄、排行榜与致谢页
- P1–P4 本地档案、个人最佳纪录、3–6 项派对赛与总领奖台
- 六项目首次教学：手柄动画示范、真实输入练习、按玩家 / 项目保存完成状态

**连接**：
- hub 支持 BLE 手柄、手机网页、模拟手柄
- Regina 自制固件 200 Hz

**还缺的**：
- 音频：四条音频总线与音量保存，已有主菜单 / 大厅循环音乐及成绩胜利短曲（CC0）
- 玩家 / 进度：已有四个本地档案、各项目 / 地图个人最佳；存档已有版本、校验、备份恢复与旧档升级，仍可扩展档案槽
- 模式：
  - 已有派对 / 大赛模式；六项目真机连赛仍需回归
  - 单人已有三档电脑对手和每项目三档分数挑战，难度与目标仍需真人试玩校准
  - 已有教学框架与六项目练习规则，真机手势与四人渲染仍待回归
- 菜单：设置、手柄管理、纪录、致谢均可直接进入；六项目已有实际场景预览图，随鼠标、键盘和手柄焦点同步
- 发布：没有打包；已有游戏内致谢摘要，二进制发布还需完整依赖许可
- 性能：2 人分屏高画质下，滑板约 32 fps、滑雪约 38 fps，离 60 还差不少

## 推荐顺序

先做**游戏外壳**（M1 的核心部分），再继续做新项目。

原因：音量 / 音乐、纪录、玩家档案、派对积分、教学、公共回放和领奖台，每个项目都要接。先把接口定好，后面 6 个新项目一开始就接上，不用回头逐个改。这和之前“先适配所有游戏通用的东西”是同一个思路。

M1 核心 → M2（高尔夫 → 乒乓球 → 网球 → 水上摩托 → 拳击 → 排球）→ M3 → M4。M1 里的“新手教学”跟着每个项目一起做。

## 需要你决定的

1. **顺序**：按推荐先做 M1 外壳，还是先把新项目做完？
2. **发布范围**：只给自己 / 朋友用（便携 zip 就够），还是要公开发布（要安装包、商店页、更严的测试）？
3. **派对模式**：固定一组项目，还是每次自选或随机？要不要加小队对抗（2v2 合计积分）？
4. **单人内容**：做到什么程度？电脑对手 + 挑战星数就够了，还是要有生涯 / 解锁？

## 新项目统一要求

- 继承 `RSPartyGame`，支持 1–4 人分屏，`--demo=N` 机器人能玩完一局
- 体感输入用 `RSMotionControls` / `RSMotionGestures`
- 震动用 `haptic(p, "名字")`
- 文字用 `tr()`，跑 `tools/i18n_check.py` 确认 0 缺失
- 接 M1 的接口：纪录、派对积分、教学、音频总线、公共开场 / 回放 / 领奖台
- 用真实 CC0 素材：Poly Haven 材质和 HDRI、MPFB 人物、CC0 音效；玩法几何可以代码生成，但要贴材质
- 有多张地图时在大厅选；加主菜单入口；README 写玩法和调试参数
- 截图检查：2 人和 4 人分屏、中英文、每张地图
