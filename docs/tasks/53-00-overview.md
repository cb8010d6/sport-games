## 性能卡的验收口径

用户规则：不跑完整对局、截图巡检和大规模基准矩阵。每张性能卡只需要：

1. 在 `game/tests/test_perf.gd` 加一个检查函数，打印一行 `RS_PERF_<主题>: <改前> -> <改后>`（数量、字节、次数之类能在无界面下算出来的数），并断言改后的值；
2. 跑 `python tools/test_perf.py --godot <Godot>`，结果写进 PR；
3. 需要真实帧率的，在 PR 里写“未测，留给最终试玩”，不要自己跑 `tools/bench.py` 矩阵。

`test_perf.gd` 已经有“CI 不检出角色模型就跳过”的写法（`_riders_at_30fps()`，第 158–196 行），用到角色模型的检查照抄这个判断。
