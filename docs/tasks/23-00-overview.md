# 23-00 · 局域网联机 MVP

## 目标 / 范围外

甲在「局域网联机」建房，乙在同一局域网从列表选房，找不到时手动输入主机地址。两台电脑各用自己的手柄和分屏，准备后同场跑滑板或滑雪；能看到对方的幽灵和最终名次，然后回同一个大厅再来一局。

沿用 [已采纳的设计](../LAN_PLAY.md)：总计 2–4 人、每台电脑至少一名本地玩家，远端幽灵无碰撞。其他运动、派对大赛、公网匹配、共享物理、局中重连和主机迁移留待后续。

## 接口契约

- 正式游戏允许玩家选择私有 IPv4 网卡地址。建房方对所选局域网广播房间，有手动加入作为后备。默认不在公网接口或所有接口上监听，不自动修改防火墙或开放路由器端口。
- CI、自动化用例和 agent 自测显式只绑定、连接和发送到 `127.0.0.1`。双实例发现用本机单播，禁止自动测试发广播或接触真实局域网。产品地址规则可用纯数据测试覆盖。
- 主机确认入场、开始、完赛名次和最终结果；每机仍只模拟本地玩家，幽灵走独立显示路径，LAN 对局不写个人纪录、单人挑战或派对积分。
- 正式接口和协议随对应实现 PR 落地。详细编码参见 LAN_PLAY 附录。后续可加完整发布工件来源清单、固定证据摘要和扩展延迟矩阵，首卡只落实设计要求的实际兼容性比较。
