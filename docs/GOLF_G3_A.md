# 高尔夫 G3-A：等价抽离粗网格

本片是[M1](GOLF_DESIGN.md)的内部切片，接在[G2](GOLF_G2.md)之后。只分离原有粗网格，不启用果岭细化、界外修复、水/树碰撞或球物理；占位输入、144 tick飞行及禁纪录规则保持不变。

## 职责与接口

[`RSGolfCourse`](../game/scenes/golf/golf_course.gd)保留HOLES/SDF、噪声种子、RNG、地形公式、水/树/球洞、材质及环境。`_build_heights()`按原顺序准备池塘水位、果岭与发球台参数，再以`raw_height_at(x,z)`进行一次烘焙。公式内部运算及条件顺序保持不变。

[`RSGolfSurface`](../game/scenes/golf/golf_surface.gd)是RefCounted，不持有course、Node或构建Callable。私有PackedFloat32Array是唯一高度缓存；运行查询只读缓存，不创建数组或字典、不回调原公式。

| 接口 | A中的契约 |
|---|---|
| `build(at, cell_count, sample_height)` | 有限原点、正整数单元数、有效Callable；每个规范顶点按z外层/x内层采样一次，前置条件和有限高度以assert检查。再次build替换整份缓存。 |
| `origin / cells` | 只读原点与粗单元数；顶点尺寸为cells+1，单元仍为2.5m。 |
| `height_at(x,z)` | 原来的两片三角插值、原对角线和算术顺序。保留域外夹取及最大边缘`vertices-1.001`偏移。 |
| `normal_at(x,z)` | 保留±0.35m高度查询差分；渲染顶点仍用±一个2.5m网格邻点差分与边缘邻点夹取。 |
| `geometric_normal_at(x,z)` | 返回所选粗三角的向上单位面法线；这是纯几何查询，不实现球碰撞。 |
| `contains_xz(x,z)` | 包含外边缘的网格矩形检查；不是界外判定，不替代course的规则。 |
| `chunk_mesh(Rect2i)` | 参数是半开粗单元矩形，须完全位于网格内。保持原顶点、法线、索引和chunk顺序。 |

不预构建未来B的细化patch或三角访问表。`triangle_at/cell_triangles/triangle_vertex`等接口待实际细化需要时加入；A没有宣布它们已支持。

## 等价与独立测试

运行`python tools/test_golf_surface.py --godot <Godot>`，使用临时用户目录、受控子进程和UDP 47800占用检查。错误、泄漏、超时或写入`records.cfg`均失败，不停止其他实例。

[`golf_surface_coarse.json`](../game/tests/data/golf_surface_coarse.json)来自抽离前提交`3241470`的真实Godot 4.7.2运行值：两图共78个高度/查询法线样本、96个chunk计数及30组顶点/渲染法线样本。可移植断言使用0.0001m高度/位置及0.0001单位法线距离容差；不把同机字节hash当作跨平台要求。

| 固定输入/比较 | 预期 |
|---|---|
| 单个2.5m单元，ABC高度0、D高度10，查询归一化(.25,.25)/(.75,.75) | 高度分别0/5，能区分三角插值与双线性插值。 |
| 同一单元查询最外角及更远处 | 均9.98，明确保留A的旧边缘偏移；B再按已批准方案移除。 |
| 平面`2x-3z+7`，内部查询 | 高度解析解一致，查询/面法线为normalize(-2,1,3)。 |
| 构建后反复查询、生成mesh；释放sampler；再以新原点/尺寸build | 回调次数仅等于顶点数、不会保留sampler所有者、旧缓存被替换。 |
| 非线性网格在第48单元切chunk | 重复边的顶点与渲染法线完全相同，不重新采样。 |
| 实际发出的每片三角内部采样点 | 从其顶点独立算重心高度及cross面法线，与surface查询比较；不复制网格寻址公式作为期望。 |

同机另用原版私有夹具副本运行，只调整抽离后的字段访问；对比旧golden的全部查询、96个chunk的顶点/法线/索引SHA256和样本。原golden不改写，hash留在私有证据中。

## 验证记录

Godot 4.7.2 headless实测：surface专用639项通过，375040次独立三角查询（包含两图全部374714片地形三角），最大高度误差在9位小数输出精度下为0m，最大面法线距离0.000000182。旧版全部78查询、96个chunk及每chunk三类hash/样本全等；两图仍54/42个chunk、211434/163280片地形三角。无引擎错误、环境诊断、泄漏诊断或纪录文件。

G2两图demo1/2/4共884项和两个非法delta拒绝检查均通过，合计886项；暂停/重开/换图/断线/释放及禁纪录继续有效。工具69项及130子测试、中枢62项、Node素材测试8项通过。首次surface测试漏写WeakRef类型触发解析错误，已保留失败日志并修正后重跑。

公共启动smoke的15组通过，沿用原有静态资源退出诊断排除口径。规范0错误（3个原有大文件警告）、i18n475项/0缺失/0多余、Ruff通过；strict publication扫描1170个文件、0发现；素材缓存222项一致、0下载、0缺失。导入受控完成，仅新增的47组Godot默认import设置已核实后还原，新脚本UID保留。

本片在Windows同机4.7.2验证，跨平台执行尚未实测；不测GPU/FPS，headless构建时间不作为B的实渲染载入门槛。B的4人平均FPS下降超过5%或载入增加超过1s时暂停，由维护者后续串行测量；A审核前不开始B。
